# Corkos

A cork board framework for the web.

> ⚠️ **Status: Early design phase.** This repository is being scaffolded. The first usable release will be announced here.

## What is Corkos?

Corkos is a UI framework for building web applications around the metaphor of a personal cork board: a space where users pin, arrange, and connect notes, windows, and content. It is designed to be:

- **Responsive by default**, with native experiences for desktop (floating windows) and mobile (springboard).
- **Accessible by design**, including a simple-mode for users who benefit from linear, predictable navigation.
- **Open source**, MIT-licensed, and reusable for any application that wants to embrace the cork board paradigm.

The first application built on top of Corkos is [agenda.madrid](https://agenda.madrid), a cultural agenda for the city of Madrid.

## Status

This project is in early design phase. The npm package `@fzabalegui/corkos` currently reserves the name; no functional code has been published yet.
